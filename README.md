
# 🛡 SecureCheck

LINK : https://shubhzcore.github.io/Secure-Check/

### Password Security Checker

SecureCheck is a cybersecurity-focused web application
that helps users analyze password strength.

## Features

- Password strength analysis
- Security checklist
- Show and hide password
- Uppercase, lowercase, numbers and symbols
- Responsive dark-themed interface

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Privacy & Security

- Password analysis runs locally in the browser.
- Passwords are not stored by this application.
